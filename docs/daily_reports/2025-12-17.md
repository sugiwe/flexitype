### 練習ページの個別URL化（数値IDベース）

**目的:**
- 練習ページのURLを個別化し、将来的なDB化を見据えた設計に変更
- 各練習に固有のURLを割り当て、拡張性を向上

**実装内容:**

#### 1. URL設計の検討と決定

**当初案: カテゴリ + スラッグ方式**
```
/practices/:category/:lesson_id
例: /practices/word_practice/beginner_words
```

**課題:**
- スラッグの一意性管理が複雑
- カテゴリ変更時にURLが変わる
- ユーザーがレッスンを作成する機能を追加する際に複雑化

**最終案: シンプルな数値IDベース**
```
/practices/:id
例: /practices/1, /practices/7
```

**採用理由:**
- DB化時に自動採番IDをそのまま使える
- Rails標準の`resources`ルーティングと親和性が高い
- カテゴリ変更に強い（URLが不変）
- シンプルで管理しやすい
- YAGNI原則に従い、不要な複雑さを排除

#### 2. YAMLファイルの数値ID化

```yaml
# 変更前
lessons:
  word_practice:
    lessons:
      - id: "beginner_words"
        name: "初級単語"

# 変更後
lessons:
  word_practice:
    lessons:
      - id: 7
        name: 初級単語
```

- 全16レッスンに数値ID（1-16）を割り当て
- スラッグ（文字列ID）は削除してシンプル化
- Rubyスクリプトで一括変換を実施

#### 3. ルーティングの変更

```ruby
# 変更前
get "practice", to: "practice#index"

# 変更後
resources :practices, only: [ :show ]
```

- Rails標準の`resources`ルーティングを使用
- URL: `/practices/1`、`/practices/7` など

#### 4. LessonLoaderの全面改修

**新規メソッド:**
```ruby
# 全レッスンをフラットな配列として取得（ID順）
def self.all_lessons_flat
  @all_lessons_flat ||= begin
    lessons = []
    all_lessons.each_value do |category_data|
      category_data["lessons"].each do |lesson|
        lesson["category"] = category_data["category"]
        lesson["category_description"] = category_data["description"]
        lesson["requires_login"] = category_data["requires_login"]
        lesson["premium"] = category_data["premium"]
        lessons << lesson
      end
    end
    lessons.sort_by { |l| l["id"] }
  end
end
```

**変更メソッド:**
- `find_lesson(id)`: 数値IDから直接レッスンを検索
- `get_practice_items(id)`: 数値IDベース
- `get_lesson_info(id)`: 数値IDベース

#### 5. PracticesControllerのシンプル化

```ruby
# 変更前（PracticeController#index）
def index
  category_key = params[:category] || "word_practice"
  lesson_id = params[:lesson] || "beginner_words"
  @lesson_info = LessonLoader.get_lesson_info(category_key, lesson_id)
  @words = LessonLoader.get_practice_items(category_key, lesson_id)
  # デフォルトフォールバック処理...
end

# 変更後（PracticesController#show）
def show
  lesson_id = params[:id]
  @lesson_info = LessonLoader.get_lesson_info(lesson_id)
  @words = LessonLoader.get_practice_items(lesson_id)

  # レッスンが見つからない場合は404リダイレクト
  if @lesson_info.nil? || @words.empty?
    redirect_to root_path, alert: "レッスンが見つかりませんでした。"
    return
  end
end
```

- コントローラ名を`PracticeController` → `PracticesController`に変更
- アクション名を`index` → `show`に変更
- デフォルトフォールバック処理を削除し、404処理に変更

### Rubyスクリプトでの一括変換

YAMLファイルの一括変換にRubyスクリプトを使用:
```ruby
data = YAML.load_file(file_path)
lesson_id = 1
data['lessons'].each do |category_key, category_data|
  category_data['lessons'].each do |lesson|
    lesson['id'] = lesson_id
    lesson.delete('slug')
    lesson_id += 1
  end
end
File.write(file_path, data.to_yaml)
```

### 2. 左カラムサイドバーレイアウトの実装

**SaaS型アプリケーションのような洗練されたUIに全面リニューアル**

#### レイアウト構造の変更

従来の上部ヘッダー方式から、左サイドバー + 右メインコンテンツの構造に変更：

```
┌─────────────────────────────────────────┐
│  左サイドバー      │  右メインコンテンツ    │
│  (300px固定)      │  (残り幅)            │
│                   │                     │
│  - ロゴ           │  - ページコンテンツ   │
│  - ナビゲーション  │                     │
│  - 広告スペース    │                     │
│  - ユーザー情報    │                     │
└─────────────────────────────────────────┘
```

#### サイドバーの詳細構成

1. **ロゴエリア（固定）**
   - サービス名「Typnix」と説明文
   - ホームへのリンク

2. **ナビゲーションメニュー（スクロール可能）**
   - ホーム
   - キーマップ設定（ログイン時のみ表示）
   - アクティブページのハイライト表示
   - アイコン付きのわかりやすいUI

3. **広告スペース（300x250px）**
   - Google AdSenseの標準サイズ「レクタングル（中）」に対応
   - 常に表示される固定位置
   - padding なしでサイドバー幅をフル活用

4. **ユーザー情報・認証エリア（最下部固定）**
   - ログイン前: Google認証ボタン + 説明文
   - ログイン後: ユーザーアイコン（イニシャル）、名前、メールアドレス、ログアウトボタン

#### 技術的な実装

**サイドバーの幅調整プロセス:**
- 初期: 256px (w-64)
- 中間: 320px (w-80) - 広告に padding を含む想定
- 最終: 300px (style指定) - 広告が幅をフル活用

**Flexboxレイアウト:**
- サイドバー: `flex flex-col` で縦方向の構成
- ナビゲーション: `flex-1` でスクロール可能な可変エリア
- ユーザー情報: 常に最下部に固定

**ファイル変更:**
- `app/views/layouts/application.html.slim`: サイドバー全体の実装
- `app/views/home/index.html.slim`: ヘッダー削除、シンプル化
- `app/views/practice/index.html.slim`: ヘッダー削除、インデント修正
- `app/views/keymaps/edit.html.slim`: ヘッダー削除、インデント修正

# 日本語レッスン案

**作成日:** 2026-01-20
**ステータス:** 企画中
**目的:** 日本語タイピング練習用のレッスン体系を整備する

---

## 📋 全体構成

### カテゴリー構成

1. **日常会話（初級・中級・上級）**
2. **ビジネス（初級・中級・上級）**

### 難易度設計

| 難易度 | 内容 | 記号 | 形式 |
|--------|------|------|------|
| **初級** | 指運びが簡単な単語のみ | 伸ばし棒（ー）のみ | 単語のみ |
| **中級** | 指運びが難しめの単語を含む | カッコ、句読点、感嘆符なども含む | 単語のみ |
| **上級** | 複雑な単語 + 短文 | すべての記号を含む | 2-3語の短文 |

## 🌟 特別レッスン: 2025年の話題の言葉

**テーマ:** 2025年に話題になった流行語・新語を使ったタイピング練習

**注意:** これらの言葉は一般的な流行語であり、著作権法上の「著作物」には該当しません。

### 単語リスト（10語）

```json
{"text":"えっほえっほ","display":"エッホエッホ"}
{"text":"おーるどめでぃあ","display":"オールドメディア"}
{"text":"くまひがい","display":"クマ被害"}
{"text":"こくほう","display":"国宝"}
{"text":"ここここまい","display":"古古古米"}
{"text":"しょうわ100ねん","display":"昭和100年"}
{"text":"とらんぷかんぜい","display":"トランプ関税"}
{"text":"にき","display":"二季"}
{"text":"はたらいてまいります","display":"働いてまいります"}
{"text":"みゃくみゃく","display":"ミャクミャク"}
```

### レッスン作成時の設定

**レッスン名（日本語）:** 2025年の話題の言葉
**レッスン名（英語）:** 2025 Trending Words
**説明（日本語）:** 2025年に話題になった流行語や新語を使ったタイピング練習です。
**説明（英語）:** Typing practice with trending words and new expressions from 2025.
**カテゴリー:** 日常会話（日本語） または 特別レッスン
**問題数:** 10
**公開設定:** 公開する（一般ユーザーも練習可能）

### 難易度分析

- **指運び:** 中（「しょうわ」「はたらいて」などやや複雑な拗音あり）
- **記号:** なし（全てひらがな・カタカナのみ）
- **長さ:** 短〜中（2-9文字）

### 推奨配置

- **初級〜中級の間**: 記号がないため初級扱いも可能だが、一部の単語（「働いてまいります」など）が長いため中級寄り

## 📝 レッスン作成時の注意点

### JSON形式のルール

**単語のみ:**
```json
{"text":"きょう","display":"今日"}
```

**記号を含む単語:**
```json
{"text":"うれしい！","display":"嬉しい！"}
{"text":"「はい」","display":"「はい」"}
```

**短文（2-3語）:**
```json
{"text":"おはよう。げんき？","display":"おはよう。元気？"}
```

### 記号の入力パターン

| 記号 | 入力キー | 使用例 |
|------|---------|--------|
| ー | `-` | ラーメン、コーヒー |
| 、 | `,` | はい、そうです |
| 。 | `.` | ありがとう。 |
| 「 | `[` | 「こんにちは」 |
| 」 | `]` | 「こんにちは」 |
| ！ | `!` | 嬉しい！ |
| ？ | `?` | 何？ |
| （ | `(` | （笑い） |
| ） | `)` | （笑い） |

## 📋 概要

Typnixに日本語タイピング練習機能を追加しました。ひらがな入力に対応し、漢字・カタカナの表示機能も実装しています。

---

## ✅ 実装内容

### 1. データ構造の変更

#### マイグレーション
**ファイル:** `db/migrate/20260119062725_add_display_field_to_lesson_items.rb`

**変更内容:**
- `Lesson.items` の構造を変更: 文字列配列 → ハッシュ配列
- 後方互換性を保持（既存データは自動変換）

**変更前:**
```ruby
items: ["hello", "world"]
```

**変更後:**
```ruby
items: [
  { "text" => "hello", "display" => nil },
  { "text" => "world", "display" => nil }
]
```

**日本語レッスンの例:**
```ruby
items: [
  { "text" => "きょう", "display" => "今日" },
  { "text" => "てんき", "display" => "天気" }
]
```

#### ロールバック対応
`display` フィールドが不要になった場合、`rails db:rollback` で元の文字列配列に戻せます。

---

### 2. フロントエンド実装

#### ローマ字変換ロジック
**ファイル:** `app/javascript/lib/romaji_converter.js`

**機能:**
- ひらがな → ローマ字の変換
- 複数パターン対応（例: `し` → `si` / `shi`）
- 撥音「ん」の柔軟な入力対応
  - 次が子音: `n` / `nn` 両対応（例: `tenki` / `tennki`）
  - 次が母音・n・y: `nn` 必須（例: `konnnichiha`）

#### タイピング制御
**ファイル:** `app/javascript/controllers/typing_controller.js`

**主要機能:**
1. **3段表示**
   - 最上段: ひらがな読み（小さく、グレー）
   - 中段: 表示用テキスト（大きく、メイン表示） - `display` フィールドがあれば漢字・カタカナ
   - 下段: ローマ字ガイド（小さく、入力状態を色分け）

2. **動的パターン切り替え**
   - ユーザーの入力に応じて自動的にローマ字パターンを切り替え
   - 例: `co` → `cho`、`si` → `shi`

3. **英語・日本語の統一**
   - WPM計算: エラー状態以外の全キー入力をカウント
   - 正答率計算: `(typedChars - mistakeCount) / typedChars * 100`

---

### 3. バックエンド実装

#### レッスンフォーム
**ファイル:** `app/controllers/my/lessons_controller.rb`, `app/views/my/lessons/_form.html.slim`

**機能:**
1. **フォーマット変換ヘルパー** (`format_items_for_form`)
   - DB保存形式 → フォーム表示形式
   - `display` あり → JSON表示
   - `display` なし → プレーンテキスト表示

2. **JSON形式のパース** (`lesson_params`)
   - プレーンテキスト: 1行1単語
   - JSON形式: `{"text":"ひらがな","display":"表示用テキスト"}`
   - 混在OK（1レッスン内で両形式を使用可能）

3. **UI改善**
   - JSON形式の入力例を表示
   - モノスペースフォントで読みやすく

## 🔧 技術詳細

### ローマ字変換の仕組み

**例: 「しょうりした」（勝利した）**

1. **ひらがな → ローマ字データ変換**
```javascript
[
  { kana: 'し', roma: ['si', 'shi', 'ci'] },
  { kana: 'ょ', roma: ['lyo', 'xyo'] },
  { kana: 'う', roma: ['u', 'wu'] },
  { kana: 'り', roma: ['ri'] },
  { kana: 'し', roma: ['si', 'shi', 'ci'] },
  { kana: 'た', roma: ['ta'] }
]
```

2. **デフォルトパターン生成**
```javascript
"silyourisita"  // 各文字の最初のパターンを連結
```

3. **ユーザー入力に応じた動的切り替え**
- ユーザーが `s` → `h` と入力 → `shi` に切り替え
- ユーザーが `l` → `y` と入力 → `lyo` のまま（部分一致）
- ユーザーが `x` → `y` と入力 → `xyo` に切り替え

### 撥音「ん」の処理

**ルール:**
- 次の文字が **子音**（k, s, t など）で始まる → `n` / `nn` 両対応
- 次の文字が **母音**（a, i, u, e, o）、**n**、**y** で始まる → `nn` 必須

**実装:**
```javascript
// 撥音「ん」の特殊処理
if (oneChar === 'ん') {
  if (i + 1 < hiragana.length) {
    const nextChar = hiragana[i + 1]
    const nextRoma = ROMAJI_MAP[nextChar]
    if (nextRoma && nextRoma[0]) {
      const firstSound = nextRoma[0][0]
      const vowels = ['a', 'i', 'u', 'e', 'o']
      if (!vowels.includes(firstSound)) {
        // 子音の前では'n'も許容
        result.push({ kana: 'ん', roma: ['nn', 'n', 'xn'] })
        return
      }
    }
  }
  // 母音の前、または文末では'nn'必須
  result.push({ kana: 'ん', roma: ['nn', 'xn'] })
}
```

**例:**
- 「てんき」(天気): `tenki` ✓ / `tennki` ✓
- 「こんにちは」: `konnnichiha` ✓ / `konnichiha` ✗

## 📝 注意事項

### 既知の制約

1. **IME無効化**
   - 日本語IMEを使わず、ローマ字入力のみ受け付ける
   - `inputmode="latin"`, `style="ime-mode: disabled;"` で制御

2. **後方互換性**
   - マイグレーション後も既存の文字列配列データは動作する
   - 自動的にハッシュ配列に変換される

3. **表示優先順位**
   - `display` フィールドがある → 表示用テキストを使用
   - `display` フィールドがない → ひらがなをそのまま表示

## 🐛 トラブルシューティング

### マイグレーションエラー

**症状:** マイグレーション実行時にエラー

**原因:** 既存データが不正な形式

**対処法:**
1. `rails console` でデータを確認
```ruby
Lesson.where("items IS NOT NULL").each do |lesson|
  puts "Lesson #{lesson.id}: #{lesson.items.class}"
end
```

2. 不正なデータを修正
```ruby
lesson = Lesson.find(xxx)
lesson.update(items: ["word1", "word2"])
```

### 日本語レッスンが動作しない

**症状:** 日本語レッスンが英語として認識される

**原因:** `isJapaneseText` 関数の判定ミス

**対処法:**
1. ブラウザコンソールでデバッグ
```javascript
console.log(romajiConverter.isJapaneseText("こんにちは"))  // true
console.log(romajiConverter.isJapaneseText("hello"))       // false
```

2. データ形式を確認
```ruby
lesson = Lesson.find(xxx)
puts lesson.items.inspect
# => [{"text"=>"こんにちは", "display"=>"こんにちは"}]
```

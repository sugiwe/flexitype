### 3. 複数クエリの最適化 - My::LessonRecordsController

**影響範囲**: 1ファイル
**作業量**: 小（30分）
**優先度**: 中（パフォーマンス改善）

**対象箇所**: `app/controllers/my/lesson_records_controller.rb:13-16`

**現状:**
```ruby
@total_count = @filtered_records.count
@average_accuracy = @filtered_records.average(:accuracy)...
@average_wpm = @filtered_records.where.not(wpm: nil).average(:wpm)...
# 3回のクエリが発生
```

**改善案:**
```ruby
stats = @filtered_records.select(
  "COUNT(*) AS count",
  "AVG(accuracy) AS avg_accuracy",
  "AVG(wpm) AS avg_wpm"
).where.not(wpm: nil).first

@total_count = stats.count
@average_accuracy = stats.avg_accuracy&.round(1) || 0
@average_wpm = stats.avg_wpm&.round(1) || 0
```
